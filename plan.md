# План реалізації віддаленого контролю зображень

## 1. Налаштування ліміту (Вкладка "ВІДДАЛЕНЕ КЕРУВАННЯ")
- Додати в UI вкладки "Віддалене керування" нове налаштування: **"Кількість медіа для віддаленого прев'ю"** (наприклад, 3 або 5).
- Забезпечити збереження цього параметру. Якщо налаштування глобальне для воркера, зберігати його у документі конфігурації воркера у Firebase (Firestore) або безпосередньо в параметрах завдання, щоб воркер знав, скільки файлів відправляти.

## 2. Логіка Воркер ПК (Відправка прев'ю)
- Знайти місце в коді (backend/app.go або відповідний сервіс), де процес зупиняється на етапі **"КОНТРОЛЬ ЗОБРАЖЕНЬ"**.
- Змінити логіку: перед тим як увійти в стан очікування дій користувача, воркер перевіряє чи увімкнене віддалене керування та бере перші `N` згенерованих зображень/відео.
- **Завантаження:** Воркер завантажує ці `N` файлів у Firebase Storage (в окрему директорію завдання, наприклад `tasks/{taskId}/previews/`).
- **Оновлення статусу:** Після успішного завантаження воркер записує отримані публічні URL-адреси (або шляхи) у документ завдання в Firestore і встановлює статус завдання (наприклад, `status: "WAITING_REMOTE_CONTROL"`).

## 3. Логіка Майстер ПК (Перегляд та дія)
- **Підписка на зміни:** Майстер ПК слухає оновлення завдань з Firebase.
- Коли завдання переходить у статус `WAITING_REMOTE_CONTROL`, Майстер ПК отримує URL-адреси завантажених прев'ю.
- **Відображення:** Додати UI для відображення цих картинок/відео (можна інтегрувати в існуючу вкладку ГАЛЕРЕЯ або прямо в панель ВІДДАЛЕНЕ КЕРУВАННЯ).
- **Керування:** Надати Майстру кнопки дій для цього завдання:
  - `Підтвердити` (все ок, продовжуємо роботу).
  - `Перегенерувати / Редагувати` (відхилено).
- Після натискання Майстер ПК оновлює документ завдання в Firestore, передаючи відповідну команду (наприклад, змінює статус на `REMOTE_CONTROL_APPROVED` або `REMOTE_CONTROL_REJECTED`).

## 4. Відновлення роботи Воркер ПК
- Воркер ПК повинен слухати зміни свого поточного завдання у Firestore.
- Коли воркер отримує статус `REMOTE_CONTROL_APPROVED`, він автоматично знімає локальну паузу і переходить до наступного кроку пайплайну (наприклад, генерація відео або рендер).
- Якщо отримує `REMOTE_CONTROL_REJECTED` (або нові параметри), він скасовує поточні результати і запускає процес перегенерації.
- **Очищення:** (Опціонально) після завершення завдання або прийняття рішення, видаляти файли прев'ю з Firebase Storage для економії місця.
