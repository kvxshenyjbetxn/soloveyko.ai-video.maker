# 🟢 Skill: Старт сесії (Start Wiki)

## 🎯 Мета
Відновити контекст проєкту на початку нової сесії, щоб агент розумів стан та історію роботи.

## 📋 Кроки (виконувати СТРОГО по порядку)

1. **Прочитай `.wiki/SCHEMA.md`** — актуальні правила та обмеження.
2. **Прочитай `.wiki/index.md`** — загальна карта проєкту.
3. **Прочитай останні 5-10 записів `.wiki/log.md`** — історія останніх змін. **НЕ читай весь файл!** Якщо файл великий — обмежся останніми записами.
4. **Прочитай `.wiki/architecture.md`** — структура модулів. Якщо файл великий — зосередься на заголовках секцій та модулях, що стосуються поточної задачі.
5. **Якщо є `decisions.md`** — швидко проглянь останні 2-3 рішення.
6. **Повідом користувачу** українською мовою:
   - "Контекст відновлено."
   - Коротке резюме: на чому зупинилися, яка остання задача, який статус.
7. **Почни вести сесійний щоденник** — внутрішній список у пам'яті (НЕ файл!) куди будеш записувати кожну дію цієї сесії. Формат:
   - Задача: що робиш.
   - Дії: що конкретно зробив (створив X, додав Y, виправив Z).
   - Файли: які файли змінено/створено.
   - Рішення: які технічні рішення прийнято і чому.
   - Проблеми: що не вийшло або відкладено.
8. **Нагадай користувачу** (одноразово): "Wiki закрита для запису. Використовуй `checkpoint` або `end` щоб зафіксувати зміни."

## ✅ Результат
Агент повністю зорієнтований у проєкті, знає останній контекст, готовий до роботи. Сесійний щоденник ініціалізовано. Wiki — тільки читання.

## 🚫 Заборони
- Не читай весь `log.md` — тільки останні 5-10 записів.
- Не змінюй жодні файли на цьому етапі.
- Не пропускай крок 6 — користувач має бачити, що контекст відновлено.
- Не створюй файл для сесійного щоденника — веди його в пам'яті.
