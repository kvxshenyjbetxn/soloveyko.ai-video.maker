# 🆕 Skill: Ініціалізація Wiki (Init Wiki)

## 🎯 Мета
Створити базу знань `.wiki/` для **НОВОГО** проєкту з нуля. Використовується коли проєкт ще не має wiki-системи.

## 📋 Кроки (виконувати СТРОГО по порядку)

### Частина 1: Перевірка

1. **Перевір чи вже існує `.wiki/`** у корені проєкту.
   - Якщо так — запропонуй використати `skill-index-wiki` замість цього skill.
   - Якщо ні — продовж.

2. **Запитай користувача**:
   - Назва проєкту.
   - Короткий опис (1-2 речення що робить проєкт).
   - Стек технологій (основні фреймворки, мови, бібліотеки).

### Частина 2: Створення структури

3. **Створи папку `.wiki/`** у корені проєкту.

4. **Створи `.wiki/SCHEMA.md`** — скопіюй шаблон правил з цього репозиторію-шаблону (або використай стандартний).

5. **Створи `.wiki/index.md`**:
   ```markdown
   # 🗺️ Project Index
   
   Ласкаво просимо до бази знань проєкту.
   
   ## 🚀 Огляд проєкту
   [Назва] — [Опис]. Стек: [Технології].
   
   ## 📂 Основні розділи
   - [[log|📜 Журнал змін]]
   - [[architecture|🏛️ Архітектура]]
   - [[decisions|⚖️ Прийняті рішення]]
   
   ## 📁 Інструкції для агентів (instruction/)
   - [[instruction/skill-start-wiki|🟢 Старт сесії]]
   - [[instruction/skill-checkpoint-wiki|🟡 Чекпоінт]]
   - [[instruction/skill-end-wiki|🔴 Завершення сесії]]
   - [[instruction/skill-init-wiki|🆕 Ініціалізація wiki]]
   - [[instruction/skill-index-wiki|📋 Переіндексування]]
   - [[instruction/skill-link-wiki|🔗 Прив'язка Obsidian]]
   - [[instruction/skill-commit-massage|💬 Комміт-меседж]]
   
   ## 📐 Правила (див. [[SCHEMA]])
   - Мова: **УКРАЇНСЬКА**
   - Нові записи: **зверху** (після маркерів)
   - Не видаляти HTML-маркери <!-- ... -->
   ```

6. **Створи `.wiki/log.md`**:
   ```markdown
   # 🕒 Development Log
   
   Хронологічний список усіх значущих змін. Нові записи — **ВЕРХНІМ**.
   
   <!-- NEW_LOG_ENTRY -->
   
   ## [YYYY-MM-DD] | Ініціалізація wiki
   - **Задача**: Створення бази знань проєкту.
   - **Зміни**: Створено `.wiki/` з усіма файлами.
   - **Файли**: [[index]], [[architecture]], [[decisions]], [[SCHEMA]].
   - **Статус**: ✅ Завершено.
   - **Результат**: Wiki-система запрацювала.
   
   ---
   *Нові записи — після маркера <!-- NEW_LOG_ENTRY --> (зверху!)*
   ```

7. **Створи `.wiki/architecture.md`**:
   ```markdown
   # 🏛️ Architecture & System Design
   
   ## 📦 Компоненти
   
   <!-- ARCHITECTURE_COMPONENTS -->
   
   ## 🔄 Потоки даних
   
   <!-- ARCHITECTURE_DATAFLOW -->
   
   ## 🔌 Зовнішні API та сервіси
   
   <!-- ARCHITECTURE_API -->
   
   <!-- ARCHITECTURE_END -->
   
   ---
   *Нові секції — перед <!-- ARCHITECTURE_END -->*
   ```

8. **Створи `.wiki/decisions.md`**:
   ```markdown
   # ⚖️ Decision Log (ADRs)
   
   Нові записи — **ВЕРХНІМ**.
   
   <!-- NEW_DECISION_ENTRY -->
   
   | Дата | Рішення | Контекст | Наслідки |
   |:---|:---|:---|:---|
   | YYYY-MM-DD | Ініціалізація wiki | Новий проєкт потребує системи пам'яті | Створено .wiki/ |
   
   ---
   *Нові записи — після <!-- NEW_DECISION_ENTRY --> (зверху!)*
   ```

9. **Створи `.wiki/instruction/`** та скопіюй усі skill-файли:
   - `skill-start-wiki.md`
   - `skill-checkpoint-wiki.md`
   - `skill-end-wiki.md`
   - `skill-init-wiki.md`
   - `skill-index-wiki.md`
   - `skill-link-wiki.md`
   - `skill-commit-massage.md`

### Частина 3: Наповнення

10. **Проаналізуй структуру проєкту** (файли, папки, package.json / requirements.txt / інше).
11. **Заповни `architecture.md`** на основі знайдених модулів та компонентів.
12. **Заповни `index.md`** актуальним описом проєкту та стеком технологій.

### Частина 4: Фіналізація

13. **Додай `.wiki/` у `.gitignore`?** — запитай користувача. Якщо `.wiki` — Junction на Obsidian, то можливо треба ігнорувати. Якщо локальна — навпаки, комітити.
14. **Повідом користувача** українською: "Wiki-систему ініціалізовано. Файли створено: index.md, log.md, architecture.md, decisions.md, SCHEMA.md, instruction/ (7 skill-файлів)."

## ✅ Результат
- Повна структура `.wiki/` з усіма файлами та маркерами.
- `architecture.md` наповнений на основі аналізу проєкту.
- `index.md` містить актуальний опис.
- `log.md` містить перший запис про ініціалізацію.
- Користувач проінформований про результат.

## 🚫 Заборони
- Не ініціалізуй wiki якщо `.wiki/` вже існує — запропонуй `skill-index-wiki`.
- Не пропускай HTML-маркери — вони обов'язкові для роботи агентів.
- Не пиши англійською — усе українською.
- Не забувай запитати про `.gitignore`.
