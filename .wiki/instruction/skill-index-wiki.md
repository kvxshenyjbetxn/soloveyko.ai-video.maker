# 📋 Skill: Переіндексування (Index Wiki)

## 🎯 Мета
Проіндексувати та оновити документацію **існуючого** проєкту. Використовується коли структура проєкту суттєво змінилася і wiki потребує повного оновлення. Не використовувати для нових проєктів — для того є `skill-init-wiki`.

## 📋 Кроки (виконувати СТРОГО по порядку)

### Частина 1: Аналіз проєкту

1. **Проаналізуй структуру каталогів** проєкту (ключові папки, файли, точки входу).
2. **Знайди конфігураційні файли** (package.json, requirements.txt, Cargo.toml, pyproject.toml тощо) — визнач стек технологій.
3. **Визнач основні модулі та компоненти** — що за що відповідає.

### Частина 2: Оновлення wiki

4. **Онови `.wiki/index.md`**:
   - Перепиши огляд проєкту актуальними даними.
   - Онови стек технологій.
   - Перевір усі `[[WikiLinks]]` — виправ мертві посилання.
   - Додай нові сторінки якщо з'явилися.

5. **Онови `.wiki/architecture.md`**:
   - Перепиши секцію "Компоненти" на основі аналізу.
   - Онови потоки даних якщо змінилися.
   - Онови зовнішні API/сервіси.
   - Нові секції — **перед `<!-- ARCHITECTURE_END -->`**.

6. **Якщо є нові архітектурні рішення** — додай у `.wiki/decisions.md`:
   - Місце: **після `<!-- NEW_DECISION_ENTRY -->`** (зверху!).

### Частина 3: Логування

7. **Додай запис у `.wiki/log.md`**:
   - Місце: **після `<!-- NEW_LOG_ENTRY -->`** (зверху!).
   - Формат:
     ```
     ## [YYYY-MM-DD] | Переіндексування wiki
     - **Задача**: Оновлення документації після змін у структурі.
     - **Зміни**: Що було оновлено.
     - **Файли**: [[index]], [[architecture]], [[decisions]].
     - **Статус**: ✅ Завершено.
     - **Результат**: Wiki актуалізовано.
     ```

8. **Повідом користувача** українською: "Wiki переіндексовано. Усі файли оновлено."

## ✅ Результат
- `index.md` — актуальний огляд та посилання.
- `architecture.md` — актуальна структура модулів.
- `decisions.md` — нові рішення зафіксовані.
- `log.md` — запис про переіндексування.
- Немає мертвих `[[WikiLinks]]`.

## 🚫 Заборони
- Не використовуй цей skill для нових проєктів — використовуй `skill-init-wiki`.
- Не додавай записи в кінець `log.md` — тільки після маркера зверху.
- Не видаляй HTML-маркери.
- Не перезаписуй весь файл — використовуй точкове редагування.
