# Claude Code CLI — команди та флаги

> `claude [options] [command] [prompt]`  
> За замовчуванням запускає інтерактивну сесію. Для неінтерактивного виводу використовуй `-p/--print`.

---

## Основні флаги

| Флаг | Опис |
|------|------|
| `-p, --print` | Вивести відповідь і завершити роботу (для pipes/скриптів) |
| `-c, --continue` | Продовжити останню розмову в поточній директорії |
| `-r, --resume [id]` | Відновити розмову за ID сесії або відкрити інтерактивний вибір |
| `-n, --name <name>` | Задати відображуване ім'я для цієї сесії |
| `-v, --version` | Вивести версію |
| `-h, --help` | Показати довідку |
| `-d, --debug [filter]` | Увімкнути режим відлагодження (фільтр, напр. `"api,hooks"`) |
| `--verbose` | Перевизначити режим детального виводу з конфігурації |

---

## Модель та сесія

| Флаг | Опис |
|------|------|
| `--model <model>` | Обрати модель (псевдонім: `sonnet`, `opus`, або повна назва, напр. `claude-sonnet-4-6`) |
| `--agent <agent>` | Задати агента для поточної сесії (перевизначає налаштування `agent`) |
| `--agents <json>` | JSON-об'єкт з визначеннями кастомних агентів |
| `--effort <level>` | Рівень зусиль: `low`, `medium`, `high`, `xhigh`, `max` |
| `--session-id <uuid>` | Використати конкретний UUID як ID сесії |
| `--fork-session` | При відновленні створити новий ID сесії (разом з `--resume` або `--continue`) |
| `--no-session-persistence` | Не зберігати сесію на диск (тільки з `--print`) |
| `--from-pr [value]` | Відновити сесію, пов'язану з PR (номер/URL або інтерактивний вибір) |
| `--fallback-model <model>` | Автоматично перемикатись на іншу модель при перевантаженні основної (тільки з `--print`) |

---

## Системний промпт

| Флаг | Опис |
|------|------|
| `--system-prompt <prompt>` | Задати системний промпт для сесії |
| `--append-system-prompt <prompt>` | Додати текст до стандартного системного промпту |
| `--exclude-dynamic-system-prompt-sections` | Перенести динамічні секції (cwd, git status тощо) у перше повідомлення (покращує кешування промпту) |

---

## Інструменти (tools)

| Флаг | Опис |
|------|------|
| `--tools <tools...>` | Вказати список доступних вбудованих інструментів (напр. `"Bash,Edit,Read"`, `""` — відключити всі, `"default"` — усі) |
| `--allowedTools <tools...>` | Дозволити конкретні інструменти (напр. `"Bash(git *) Edit"`) |
| `--disallowedTools <tools...>` | Заборонити конкретні інструменти |
| `--add-dir <directories...>` | Дозволити інструментам доступ до додаткових директорій |

---

## Дозволи

| Флаг | Опис |
|------|------|
| `--permission-mode <mode>` | Режим дозволів: `acceptEdits`, `auto`, `bypassPermissions`, `default`, `dontAsk`, `plan` |
| `--dangerously-skip-permissions` | Обійти всі перевірки дозволів (тільки для ізольованих середовищ) |
| `--allow-dangerously-skip-permissions` | Зробити пропуск дозволів доступним як опцію (без автоматичного увімкнення) |

---

## Формат вводу/виводу

| Флаг | Опис |
|------|------|
| `--output-format <format>` | Формат виводу: `text` (за замовчуванням), `json`, `stream-json` (тільки з `--print`) |
| `--input-format <format>` | Формат вводу: `text` (за замовчуванням), `stream-json` (тільки з `--print`) |
| `--include-partial-messages` | Включати часткові чанки повідомлень у реальному часі (тільки з `--print` та `stream-json`) |
| `--include-hook-events` | Включати всі hook-події у вихідний потік (тільки з `stream-json`) |
| `--replay-user-messages` | Повторно надсилати повідомлення користувача зі stdin на stdout |
| `--json-schema <schema>` | JSON Schema для валідації структурованого виводу |
| `--max-budget-usd <amount>` | Максимальна сума в USD на API-виклики (тільки з `--print`) |
| `--file <specs...>` | Файлові ресурси для завантаження при старті (`file_id:relative_path`) |

---

## MCP (Model Context Protocol)

| Флаг | Опис |
|------|------|
| `--mcp-config <configs...>` | Завантажити MCP-сервери з JSON-файлів або рядків |
| `--strict-mcp-config` | Використовувати тільки MCP-сервери з `--mcp-config`, ігноруючи інші конфігурації |
| `--mcp-debug` | *(Застаріло)* Увімкнути debug-режим MCP (натомість використовуй `--debug`) |

---

## Плагіни та налаштування

| Флаг | Опис |
|------|------|
| `--plugin-dir <path>` | Завантажити плагін з директорії або .zip для цієї сесії |
| `--plugin-url <url>` | Завантажити плагін .zip за URL для цієї сесії |
| `--settings <file-or-json>` | Шлях до JSON-файлу налаштувань або JSON-рядок |
| `--setting-sources <sources>` | Comma-separated список джерел налаштувань: `user`, `project`, `local` |
| `--disable-slash-commands` | Відключити всі skills (slash-команди) |
| `--betas <betas...>` | Beta-заголовки для API-запитів (тільки для користувачів з API-ключем) |

---

## Інтеграції

| Флаг | Опис |
|------|------|
| `--ide` | Автоматично підключитися до IDE при старті (якщо доступна одна) |
| `--chrome` | Увімкнути інтеграцію Claude у Chrome |
| `--no-chrome` | Відключити інтеграцію Claude у Chrome |
| `--tmux` | Створити tmux-сесію для worktree (потрібен `--worktree`) |
| `-w, --worktree [name]` | Створити новий git worktree для сесії |
| `--remote-control [name]` | Запустити інтерактивну сесію з увімкненим Remote Control |
| `--remote-control-session-name-prefix <prefix>` | Префікс для автогенерованих імен Remote Control сесій |
| `--brief` | Увімкнути інструмент SendUserMessage для комунікації агент→користувач |

---

## Режим "bare"

| Флаг | Опис |
|------|------|
| `--bare` | Мінімальний режим: пропустити hooks, LSP, плагіни, auto-memory тощо. Встановлює `CLAUDE_CODE_SIMPLE=1`. Корисно для автоматизації та CI. |
| `--debug-file <path>` | Записати debug-логи у вказаний файл (неявно вмикає debug-режим) |

---

## Підкоманди

| Команда | Опис |
|---------|------|
| `agents` | Керування фоновими агентами |
| `auth` | Керування автентифікацією (логін/логаут) |
| `auto-mode` | Перегляд конфігурації класифікатора auto-режиму |
| `doctor` | Перевірка стану автооновлення Claude Code |
| `install [target]` | Встановити нативну збірку Claude Code (`stable`, `latest` або конкретна версія) |
| `mcp` | Налаштування та керування MCP-серверами |
| `plugin` / `plugins` | Керування плагінами Claude Code |
| `project` | Керування станом проекту Claude Code |
| `setup-token` | Налаштувати довготривалий токен автентифікації (потрібна підписка Claude) |
| `ultrareview [target]` | Запустити хмарний мультиагентний code review поточної гілки або PR |
| `update` / `upgrade` | Перевірити наявність оновлень і встановити їх |


моделі: 
claude --model sonnet
claude --model opus
claude --model haiku
