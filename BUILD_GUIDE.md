# Інструкція з компіляції Soloveyko.ai

Цей файл містить команди для збірки проекту під Windows. Оскільки проект використовує **Wails**, компіляція відрізняється від стандартної збірки Go.

## 🚀 Як скомпілювати програму (Production build)

Щоб скомпілювати фінальну версію програми **без вікна консолі** (GUI mode) та з оптимізацією:

```powershell
wails build -ldflags "-H windowsgui -s -w"
```

### Розшифровка прапорів:
- `wails build`: Стандартна команда збірки Wails (автоматично збирає фронтенд та бекенд).
- `-ldflags`: Передає параметри лінкувальнику Go.
- `-H windowsgui`: **Вимикає появу чорного вікна консолі** при запуску програми.
- `-s -w`: Зменшує розмір готового файлу (видаляє налагоджувальну інформацію).

---

## 🛠 Інші корисні команди

### 1. Режим розробки (Live Development)
Запускає програму з можливістю "гарячої заміни" коду (Hot Reload):
```powershell
wails dev
```

### 2. Тільки фронтенд
Якщо ви змінили лише UI і хочете перевірити його збірку без перезбірки всієї програми:
```powershell
cd frontend
npm run build
```

### 3. Чиста збірка
Якщо виникають дивні помилки, спробуйте очистити кеш перед збіркою:
```powershell
wails build -clean
```

---

## 📋 Вимоги для збірки
1. **Go** (1.21+)
2. **Node.js** (18+) та **npm**
3. **Wails CLI** (`go install github.com/wailsapp/wails/v2/cmd/wails@latest`)
4. **WebView2 Runtime** (зазвичай є в Windows 10/11 за замовчуванням)
